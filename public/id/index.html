Ubah Ukuran Gambar Online Gratis — Tanpa Daftar

ImageResizer adalah alat gratis yang mengubah ukuran gambar di browser Anda. Tambahkan foto, atur lebar dan tinggi dalam piksel atau persen, pilih JPEG, PNG, atau WebP, lalu unduh hasilnya. File Anda tidak pernah diunggah ke server.

Tidak perlu daftar dan tidak ada watermark. Anda bisa menambahkan beberapa gambar sekaligus, dan setiap gambar yang diproses punya tombol unduh sendiri. Gambar besar juga bisa diproses; batasnya bergantung pada memori perangkat Anda.

Yang Bisa Anda Lakukan dengan ImageResizer

Ubah ukuran dengan piksel atau persen

Isi lebar, tinggi, atau keduanya. Jika hanya satu yang diisi, sisi lainnya mengikuti rasio asli: foto 4000×3000 yang diatur selebar 1000 px menjadi 1000×750. Jika keduanya diisi, mode penyesuaian menentukan apakah gambar diskalakan tanpa dipotong, dipotong untuk mengisi ukuran, atau diregangkan.

Perkecil ukuran file

Turunkan penggeser kualitas atau masukkan ukuran file target. Dalam pengujian kami, foto 1,4 MB yang diubah menjadi lebar 1000 px berukuran 64 KB sebagai JPEG dengan kualitas bawaan, 44 KB sebagai WebP, dan 789 KB sebagai PNG. Untuk opsi lain, lihat kompresor gambar.

Potong foto online

Untuk mengambil sebagian gambar saja, gunakan alat pemotong. Anda bisa memilih rasio atau memotong bebas.

Pemrosesan massal

Tambahkan beberapa gambar, pilih pengaturan sekali, lalu klik Proses gambar. Setiap gambar yang diproses punya tombol unduh sendiri, dan tidak ada file ZIP yang dibuat.

Siapa yang menggunakan ImageResizer?

Pengguna media sosial sering butuh ukuran yang tepat, misalnya 1080×1080 untuk postingan feed Instagram atau 1080×1920 untuk Stories.

Jika foto terlalu besar untuk dikirim lewat email atau diunggah, Anda bisa memperkecil dimensinya atau menentukan ukuran file lebih dulu.

Pemilik blog atau toko online yang butuh banyak gambar dengan ukuran sama bisa menambahkannya sekaligus dan memprosesnya sekali jalan.

Untuk pas foto dan foto visa, cek ukuran yang diminta, misalnya 35×45 mm atau 51×51 mm, lalu masukkan dalam piksel.

Cara Mengubah Ukuran Gambar Online

1. Tambahkan gambar Anda. Seret ke kotak atau klik Pilih gambar. Anda bisa menambahkan lebih dari satu.

2. Pilih ukuran dan format. Pilih persentase atau dimensi, lalu isi lebar atau tinggi. Di pengaturan output, pilih JPEG, PNG, atau WebP dan, jika perlu, ukuran file target.

3. Klik Proses gambar, lalu unduh hasilnya. Gambar diubah ukurannya di browser Anda, jadi file tidak keluar dari perangkat Anda.

Pertanyaan Umum (FAQ)

Apakah gambar saya diunggah ke server?

Tidak. Gambar Anda diproses di browser dan tidak pernah diunggah ke server, jadi tetap ada di perangkat Anda.

Apakah ImageResizer benar-benar gratis?

Ya. Gratis, tanpa daftar, dan tanpa watermark.

Berapa ukuran file maksimum?

Tidak ada batas tetap. Gambar yang sangat besar bergantung pada memori browser Anda.

Format apa yang didukung?

Anda bisa menambahkan PNG, JPG, WebP, GIF, BMP, AVIF, dan SVG, lalu mengunduh sebagai JPEG, PNG, atau WebP.

Bagaimana cara memperkecil gambar ke ukuran file tertentu?

Masukkan ukuran di kolom opsional Target file size pada pengaturan output, lalu klik Proses gambar. Dalam pengujian kami dengan JPG 4000×3000, target 200 KB menghasilkan 199 KB, dan target 50 KB menghasilkan 52 KB setelah alat ini juga mengurangi jumlah piksel. Pada PNG hasilnya bisa melebihi target: target 100 KB menghasilkan 146 KB.

Bisakah saya mengubah ukuran beberapa gambar sekaligus?

Bisa. Tambahkan beberapa gambar, pilih pengaturan sekali, lalu klik Proses gambar. Setiap gambar yang diproses punya tombol unduh sendiri; tidak ada file ZIP yang dibuat.

Apakah ImageResizer menghapus data EXIF?

Ya. Dalam pengujian kami, JPG dengan tag orientasi EXIF keluar dalam posisi tegak dan tanpa blok EXIF, sehingga data kamera dan lokasi yang tersimpan di EXIF tidak ikut terbawa ke file hasil.
