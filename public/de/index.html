Kostenloser Bildgrößen-Änderer online — ohne Anmeldung

ImageResizer ist ein kostenloses Tool, das die Größe eines Bildes in Ihrem Browser ändert. Fügen Sie ein Foto hinzu, legen Sie Breite und Höhe in Pixeln oder einen Prozentwert fest, wählen Sie JPEG, PNG oder WebP und laden Sie das Ergebnis herunter. Ihre Dateien werden nie auf einen Server hochgeladen.

Es gibt keine Anmeldung und kein Wasserzeichen. Sie können mehrere Bilder gleichzeitig hinzufügen, und jedes verarbeitete Bild hat eine eigene Download-Schaltfläche. Auch große Bilder funktionieren; die Grenze hängt vom Speicher Ihres Geräts ab.

Was Sie mit ImageResizer tun können

Größe in Pixeln oder Prozent ändern

Geben Sie Breite, Höhe oder beides ein. Füllen Sie nur eines aus, folgt die andere Seite dem ursprünglichen Seitenverhältnis: Ein Foto mit 4000×3000 Pixeln und 1000 px Breite wird 1000×750. Wenn Sie beides festlegen, bestimmt der Anpassungsmodus, ob das Bild ohne Zuschnitt skaliert, zum Füllen zugeschnitten oder gestreckt wird.

Dateigröße verringern

Senken Sie den Qualitätsregler oder geben Sie eine Zieldateigröße ein. In unserem Test war ein 1,4-MB-Foto, auf 1000 px Breite verkleinert, als JPEG bei Standardqualität 64 KB groß, als WebP 44 KB und als PNG 789 KB. Weitere Optionen bietet der Bildkomprimierer.

Fotos online zuschneiden

Wenn Sie nur einen Teil eines Bildes behalten möchten, nutzen Sie das Zuschneide-Tool. Sie können ein Seitenverhältnis wählen oder frei zuschneiden.

Stapelverarbeitung

Fügen Sie mehrere Bilder hinzu, wählen Sie die Einstellungen einmal und klicken Sie auf Bild verarbeiten. Jedes verarbeitete Bild hat eine eigene Download-Schaltfläche; es wird keine ZIP-Datei erstellt.

Wer nutzt ImageResizer?

Wer in sozialen Netzwerken veröffentlicht, braucht oft genaue Maße, etwa 1080×1080 für einen Instagram-Feedbeitrag oder 1080×1920 für Stories.

Ist ein Foto zu groß für eine E-Mail oder einen Upload, können Sie zuerst die Abmessungen verringern oder eine Dateigröße festlegen.

Wer einen Blog oder einen Onlineshop betreibt und viele Bilder in gleicher Größe braucht, kann sie gemeinsam hinzufügen und in einem Durchgang verarbeiten.

Für Ausweis- und Visafotos prüfen Sie die geforderten Maße, zum Beispiel 35×45 mm oder 51×51 mm, und geben Sie sie in Pixeln ein.

So ändern Sie die Größe eines Bildes online

1. Fügen Sie Ihr Bild hinzu. Ziehen Sie es in das Feld oder klicken Sie auf Bilder auswählen. Sie können mehrere Bilder hinzufügen.

2. Wählen Sie Größe und Format. Wählen Sie Prozent oder Abmessungen und geben Sie Breite oder Höhe ein. Wählen Sie in den Ausgabeeinstellungen JPEG, PNG oder WebP und bei Bedarf eine Zieldateigröße.

3. Klicken Sie auf Bild verarbeiten und laden Sie das Ergebnis herunter. Das Bild wird in Ihrem Browser verkleinert, die Datei verlässt Ihr Gerät also nicht.

Häufig gestellte Fragen (FAQ)

Werden meine Bilder auf einen Server hochgeladen?

Nein. Ihre Bilder werden in Ihrem Browser verarbeitet und nie auf einen Server hochgeladen, sie bleiben also auf Ihrem Gerät.

Ist ImageResizer wirklich kostenlos?

Ja. Es ist kostenlos, ohne Anmeldung und ohne Wasserzeichen.

Wie groß dürfen Dateien sein?

Es gibt keine feste Grenze. Sehr große Bilder hängen vom Speicher Ihres Browsers ab.

Welche Formate werden unterstützt?

Sie können PNG, JPG, WebP, GIF, BMP, AVIF und SVG hinzufügen und als JPEG, PNG oder WebP herunterladen.

Wie bringe ich ein Bild auf eine bestimmte Dateigröße?

Geben Sie in den Ausgabeeinstellungen im optionalen Feld Target file size eine Größe ein und klicken Sie auf Bild verarbeiten. In unseren Tests mit einem 4000×3000-JPG ergab ein Ziel von 200 KB 199 KB, und ein Ziel von 50 KB ergab 52 KB, nachdem das Tool auch die Pixelzahl verringert hatte. Bei PNG kann das Ergebnis über dem Ziel liegen: 100 KB ergaben 146 KB.

Kann ich mehrere Bilder gleichzeitig verkleinern?

Ja. Fügen Sie mehrere Bilder hinzu, wählen Sie die Einstellungen einmal und klicken Sie auf Bild verarbeiten. Jedes verarbeitete Bild hat eine eigene Download-Schaltfläche; es wird keine ZIP-Datei erstellt.

Entfernt ImageResizer EXIF-Daten?

Ja. In unserem Test kam ein JPG mit EXIF-Ausrichtungsangabe aufrecht und ohne EXIF-Block heraus, daher bleiben Kamera- und Standortdaten aus dem EXIF in der verkleinerten Datei nicht erhalten.
