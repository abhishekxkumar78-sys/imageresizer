Apa yang bisa dilakukan kompresor ini?

Kompresor ImageResizer memadatkan gambar, dokumen PDF, trek audio, dan klip video langsung di browser Anda. Kompres foto dan grafik dalam format PNG, JPG, WebP, GIF, BMP, atau AVIF menjadi WebP, JPG, atau PNG. Kompres dokumen PDF banyak halaman dengan kualitas perenderan yang dapat disesuaikan. Kompres audio dalam format WAV, MP3, OGG, M4A, FLAC, atau OPUS menjadi file MP3 hemat ruang dengan kontrol bitrate dan mixdown mono opsional. Kompres video dalam format MP4, WebM, MOV, MKV, AVI, atau M4V menjadi file MP4 ringkas. Semua file diproses secara lokal di perangkat Anda dan tidak pernah diunggah ke server eksternal.

Cara kerja

  1. Pilih atau seret gambar, PDF, audio, atau video dari perangkat Anda.
  2. Sesuaikan kontrol kompresi seperti tingkat kualitas, target ukuran file, bitrate audio, atau mode kompresi video.
  3. Klik Kompres, tinjau pengurangan ukuran file, dan unduh hasilnya.

Kompresi bekerja secara lokal menggunakan standar web modern. Foto dan gambar grafis dikompresi melalui pipeline 2D browser Anda dengan pengaturan format dan kualitas yang fleksibel. Output PNG bersifat lossless, sehingga ukurannya bisa lebih besar dari aslinya; pilih WebP atau JPG untuk file yang lebih kecil. Dokumen PDF diproses dengan merender halaman menggunakan pdf.js dan menyusun kembali dokumen ringkas melalui pdf-lib. Trek audio dienkode di latar belakang pada Web Worker menggunakan lamejs untuk menghasilkan file MP3 pada bitrate pilihan Anda. Video dikompresi secara lokal menggunakan FFmpeg di WebAssembly. Mesin kompresi video berukuran sekitar 31 MB dan diunduh hanya saat Anda memulai kompresi video pertama kali, satu kali saja.

Batasan

Tidak ada batas ukuran tetap untuk gambar, tetapi foto beresolusi sangat tinggi menggunakan banyak memori browser dan dapat gagal pada perangkat dengan spesifikasi rendah. Dokumen PDF tidak memiliki batas jumlah halaman dalam kode dan diproses secara berurutan, tetapi PDF berbasis teks dapat menjadi lebih besar karena halaman dibangun kembali sebagai gambar terkompresi. Halaman PDF yang dikompresi berbasis gambar, sehingga teks tidak dapat lagi dipilih atau dicari. File audio dibatasi hingga 50 MB dan durasi maksimal 10 menit. File video dibatasi hingga 100 MB, durasi maksimal 5 menit, dan resolusi 1080p. Kurangi ke 720p hanya berlaku untuk video dengan resolusi di atas 720p: klip 60 detik atau lebih pendek dapat diproses pada resolusi penuh, sedangkan klip yang lebih panjang dari 60 detik dikunci ke 720p untuk menghemat memori perangkat.
