Muitos formulários de candidatura, portais governamentais e páginas de inscrição exigem o envio de fotos com um limite rigoroso de peso, com frequência fixado em 100 KB. Se o seu arquivo ultrapassar esse teto, o envio é recusado. As câmaras dos telemóveis e smartphones atuais captam rotineiramente fotografias com vários megabytes de tamanho. Reduzir esses ficheiros é um processo simples quando se conhecem os passos certos. Pode ajustar o peso exato da imagem diretamente no seu navegador, sem carregar o ficheiro para o servidor de ninguém.

## Por que razão os formulários impõem o limite de 100 KB

Os portais de serviços costumam estabelecer limites de tamanho para manter o armazenamento das bases de dados e o tempo de carregamento das páginas sob controlo. O mais provável é que os responsáveis queiram garantir que as candidaturas possam ser analisadas com rapidez sem consumir recursos desnecessários do servidor. Como esses sistemas verificam apenas o peso final em bytes, o seu objetivo central é atingir a marca de 100 KB mantendo rostos, assinaturas e textos bem legíveis.

## Passos para ajustar a sua foto para 100 KB

Veja como alcançar o tamanho pretendido através do nosso utilitário gratuito de [Redimensionar imagem](https://www.freeeimageresizer.com/pt/):

1. Abra o [Redimensionador de imagens](https://www.freeeimageresizer.com/pt/) e selecione o seu ficheiro, ou arraste-o para a caixa indicada.
2. Escolha JPG como formato de saída. Muitos portais aceitam apenas ficheiros JPG ou JPEG e podem recusar WebP. O formato WebP funciona perfeitamente em páginas web normais, mas para formulários verifique sempre o que o sistema aceita e, na dúvida, utilize JPG.
3. Na secção de definições de exportação, localize o campo Target file size (optional). Digite 100 e mantenha a unidade em KB.
4. Clique no botão Processar imagem. O sistema calculará os ajustes necessários para atingir esse tamanho.
5. Verifique o tamanho final indicado junto à pré-visualização e clique no botão Baixar para guardar a foto no seu dispositivo.

## Verifique os requisitos de tamanho mínimo

Alguns formulários oficiais estipulam um intervalo permitido em vez de apenas um teto máximo, como por exemplo entre 20 KB e 100 KB. Se o ficheiro ficar excessivamente leve, o sistema de receção pode rejeitá-lo. Após processar a foto, confirme o valor em kilobytes apresentado junto à pré-visualização para ter a certeza de que se enquadra dentro do intervalo exigido.

## Como o ajuste de tamanho funciona por dentro

Ao escrever 100 no campo de tamanho com a opção KB selecionada, o código define uma meta exata de 102.400 bytes. O comportamento seguinte depende do formato que selecionou.

Em formatos com perdas, como JPG e WebP, o algoritmo efetua várias passagens de teste regulando os níveis de qualidade para se aproximar do valor pretendido. Se o ficheiro continuar acima do limite mesmo com qualidade baixa, a ferramenta diminui gradualmente as dimensões do quadro em pixels até entrar no teto de 100 KB. Na versão em inglês do nosso [Compressor de imagens](https://www.freeeimageresizer.com/compress) também pode comprimir um ficheiro PDF com este mesmo campo de tamanho pretendido; os ficheiros PDF atualmente funcionam apenas nessa página em inglês e são convertidos página por página em imagens, pelo que é mais adequada para documentos digitalizados ou com muitas imagens.

O formato PNG funciona de maneira diferente, uma vez que os navegadores web não oferecem controlo de qualidade para ficheiros PNG. O PNG é um formato estritamente sem perdas. Se escolher PNG com uma meta de 100 KB, o sistema não consegue alterar a compressão das cores; a única alternativa é diminuir a largura e a altura do quadro. Por esse motivo, utilizar JPG garante uma nitidez visual muito superior ao procurar o limite de 100 KB para um documento ou foto de identificação.

Se uma fotografia contiver texturas muito complexas, o resultado pode não coincidir exatamente com 100,0 KB. Nessas situações, o programa escolhe a versão cuja diferença matemática em relação ao valor pedido seja menor e disponibiliza o download sem falhas.

## O que fazer se a imagem ficar suave ou desfocada

Converter uma fotografia de alta resolução num ficheiro de 100 KB significa abdicar de dados digitais. Texturas finas perderão inevitavelmente detalhe. Se o resultado final parecer demasiado suave, aplique estas duas soluções práticas:

Corte margens desnecessárias antes de redimensionar. Se estiver a preparar uma foto tipo passe ou um comprovativo, utilize primeiro a ferramenta de [Recortar imagem](https://www.freeeimageresizer.com/pt/crop). Remover o fundo excedente deixa menos pixels para o compressor processar, permitindo que a área principal mantenha maior definição dentro do orçamento de 100 KB.

Reduza as dimensões em pixels manualmente. Se mantiver a largura original com milhares de pixels, a compressão terá de ser muito agressiva. Se diminuir previamente a largura para uma medida razoável, como 1000 pixels, o ficheiro poderá ser guardado com uma definição de qualidade superior.
