Häufig gestellte Fragen (FAQ)

Wie funktioniert der Bildgrößen-Änderer?

Laden Sie Ihr Foto hoch, wählen Sie Abmessungen oder Prozentsatz und laden Sie das Ergebnis direkt herunter.

Sind meine Bilder sicher?

Ja, absolut. Alles wird lokal in Ihrem Browser verarbeitet. Keine Datei wird auf externe Server übertragen.

Gibt es Beschränkungen oder Gebühren?

Nein, ImageResizer ist komplett kostenlos und fügt niemals Wasserzeichen hinzu.

Wie bereite ich Fotos für Online-Shops vor?

Passen Sie Bilder auf Standardmaße (z.B. 1200x1200 px) an, damit Ihr Shop schneller lädt.

Welche Dateiformate werden unterstützt?

JPG, PNG, WebP, GIF, BMP, AVIF, HEIC und SVG.

Funktioniert das Tool auf dem Smartphone?

Ja, sowohl auf iOS (Safari) als auch auf Android (Chrome) direkt im Browser.
