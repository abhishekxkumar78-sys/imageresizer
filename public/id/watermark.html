Apa yang bisa dilakukan alat watermark ini?

Alat watermark ImageResizer menerapkan watermark teks kustom pada gambar, dokumen PDF, dan klip video langsung di browser web Anda. Tambahkan pemberitahuan hak cipta, nama pembuat, atau merek pada foto dalam format PNG, JPG, WebP, GIF, BMP, atau AVIF. Tambahkan watermark yang konsisten di semua halaman atau rentang halaman tertentu pada dokumen PDF banyak halaman. Cantumkan overlay teks pada rekaman video dalam format MP4, WebM, MOV, MKV, AVI, atau M4V untuk mengekspor file MP4 yang terlindungi. Semua proses pemberian watermark berlangsung di perangkat Anda dengan privasi lengkap, tanpa ada media yang diunggah ke server jarak jauh.

Cara kerja

  1. Pilih atau seret gambar, dokumen PDF, atau file video dari komputer atau ponsel Anda.
  2. Ketik teks watermark Anda dan sesuaikan tata letak, warna teks, ukuran font, serta transparansi.
  3. Klik Watermark, tinjau pratinjau langsung, dan unduh file Anda yang telah diberi watermark.

Watermark dirender secara lokal di perangkat Anda tanpa komunikasi ke server. Pemberian watermark gambar menggambar teks langsung pada foto Anda menggunakan canvas 2D browser. Pemberian watermark PDF memodifikasi stream dokumen langsung di browser menggunakan pdf-lib dan pdf.js, menempatkan teks vektor di setiap halaman yang dipilih. Pada video, teks dirender ke dalam bingkai overlay dan digabungkan frame-demi-frame menggunakan FFmpeg di WebAssembly. Mesin pemrosesan video berukuran sekitar 31 MB dan diunduh hanya saat Anda memberi watermark video untuk pertama kali, satu kali saja.

Batasan

Tidak ada batas ukuran tetap untuk gambar, meskipun dimensi yang sangat besar membutuhkan memori perangkat yang memadai. File PDF tidak memiliki batas halaman dalam kode, tetapi merender halaman dalam jumlah besar membutuhkan waktu pemrosesan tambahan. File video harus berukuran 100 MB atau lebih kecil, berdurasi 5 menit atau lebih pendek, dan tidak boleh melebihi resolusi 1080p (1920x1080). Kurangi ke 720p hanya berlaku untuk video dengan resolusi di atas 720p: klip 60 detik atau lebih pendek dapat diproses pada resolusi penuh, sedangkan klip yang lebih panjang dari 60 detik dikunci ke 720p untuk menghemat memori perangkat. Karena perenderan berjalan di perangkat Anda, durasi pemrosesan mencerminkan kapasitas perangkat keras Anda.

Pertanyaan yang sering diajukan

Apakah alat watermark ini gratis dan apakah file saya diunggah?

Ya, alat watermark ini sepenuhnya gratis untuk digunakan tanpa langganan, pendaftaran akun, atau watermark tambahan dari platform. Semua file tetap privat di komputer atau ponsel lokal Anda karena file Anda tidak pernah diunggah, disimpan, atau dianalisis di server eksternal.

File apa saja yang bisa saya beri watermark?

Anda dapat memberi watermark pada file gambar dalam format PNG, JPG, WebP, GIF, BMP, dan AVIF. Anda dapat memberi watermark pada dokumen PDF banyak halaman. Anda juga dapat memberi watermark pada rekaman video dalam format MP4, WebM, MOV, MKV, AVI, dan M4V serta mengunduhnya sebagai MP4.

Apa saja yang bisa saya sesuaikan?

Anda dapat menyesuaikan konten teks watermark, memilih tata letak antara Tengah, Kiri Atas, Kanan Atas, Kiri Bawah, atau Kanan Bawah, menyesuaikan ukuran font, mengatur opasitas teks dari 5% hingga 100%, dan memilih warna teks termasuk Putih, Hitam, atau pemilih warna kustom. Untuk PDF, Anda dapat memilih Semua Halaman atau halaman tertentu. Untuk video, Anda dapat memilih kualitas Tinggi, Sedang, atau Rendah.

Apa batasan untuk gambar, PDF, dan video?

Gambar tidak memiliki batas ukuran file tetap, meskipun gambar yang sangat besar membutuhkan memori browser yang cukup. Dokumen PDF tidak memiliki batasan halaman ketat dalam kode dan diproses halaman demi halaman. File video dibatasi hingga 100 MB, durasi 5 menit, dan resolusi 1080p. Kurangi ke 720p hanya berlaku untuk video di atas 720p: klip 60 detik atau lebih pendek diproses pada resolusi penuh, sedangkan klip lebih dari 60 detik dikunci ke 720p untuk menghemat memori.

Bagaimana video diberi watermark dan mengapa lebih lambat?

Pemberian watermark video membutuhkan decoding setiap frame, menempatkan tanda teks Anda, dan mengenkode ulang seluruh stream secara lokal menggunakan WebAssembly. Pemrosesan ini berjalan langsung di komputer Anda daripada di server cloud.
