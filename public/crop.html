What can this image cropper do?

ImageResizer's cropper trims photos and graphic pictures directly inside your web browser without uploading them to external servers. Crop images in PNG, JPG, WebP, GIF, BMP, or AVIF formats to custom pixel dimensions or preset aspect ratios, and download your trimmed picture as a PNG file. All cropping operations run privately on your local machine with no account signup required.

How it works

  1. Upload or drop an image file from your computer or phone.
  2. Adjust the crop box using drag handles, type exact pixel dimensions, or pick an aspect ratio preset.
  3. Click Download Crop to export your finished cropped image.

Cropping operates on your device using web standards. When you import an image, your browser renders it onto an internal 2D canvas. Moving the handles updates the crop coordinates in real time. Clicking download extracts the selected rectangular region and exports it as a PNG image file. If you set an optional target file size, the tool iteratively scales down image dimensions to approximate the target, though the resulting PNG can remain larger than the requested threshold.

Limits

There is no fixed file size limit for images in code, and our tests processed images up to 55 MB without errors. However, very large images consume significant browser memory, so performance depends on your device hardware. Output files are exported as PNG images. Because PNG is lossless, a cropped JPG or WebP photo usually becomes noticeably larger than the original (about 3 times in our test).

Frequently asked questions

Is the cropper free and do you upload my files?

Yes, the cropper is completely free to use with no hidden fees, subscriptions, or added watermarks. Your pictures remain private on your computer or phone because no image data is uploaded to remote servers.

Which image formats can I crop?

You can import and crop images in PNG, JPG, WebP, GIF, BMP, and AVIF formats. All cropped images download directly as PNG files.

What controls and aspect ratio presets are available?

You can adjust crop width and height by typing exact pixel numbers, moving corner handles, or dragging the selection box. The tool includes aspect ratio presets for Free, 1:1, 4:3, 3:2, 16:9, 9:16, 2:3, and 3:4. You can also enter an optional target file size in KB or MB, which scales down dimensions to approximate your target.

Is there an image file size limit?

There is no strict image file size limit in code, and our tests verified loading and cropping high-resolution images up to 55 MB. Processing speed and capacity depend on your available device memory.

Will cropping reduce image quality?

Cropping extracts the original pixels within your selected rectangle and exports them as a PNG image. Because PNG uses lossless compression, no pixel detail inside your crop box is discarded during export.
