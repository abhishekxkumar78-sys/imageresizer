Wenn Sie eine Reihe von Produktfotos, mehrere Aufnahmen für eine Bildergalerie oder mehrere Dokumente für einen Online-Antrag vorbereiten, kostet das Bearbeiten jedes einzelnen Bildes viel Zeit. Immer wieder dieselben Schritte Bild für Bild zu wiederholen, ist umständlich. Eine Stapelverarbeitung ermöglicht es Ihnen, alle Fotos gemeinsam auszuwählen, die Einstellungen einmal festzulegen und auf die gesamte Auswahl anzuwenden.

Unser kostenloser [Bildverkleinerer](https://www.freeeimageresizer.com/de/) unterstützt die Mehrfachverarbeitung direkt in Ihrem Webbrowser. Sie können einen Stapel von Bildern auf Ihrem Computer oder Smartphone anpassen, ohne die Dateien auf einen externen Server hochzuladen.

## Schritt-für-Schritt-Anleitung zur Stapelverarbeitung mehrerer Bilder

So passen Sie mehrere Fotos gemeinsam in einem Durchgang an:

1. Öffnen Sie den [Bildverkleinerer](https://www.freeeimageresizer.com/de/) und klicken Sie auf die Schaltfläche "Bilder auswählen", oder ziehen Sie mehrere Dateien direkt in den Bereich "Bilder hierher ziehen und ablegen". Halten Sie im Dateidialog Ihres Betriebssystems die Shift- oder Strg-Taste (Cmd auf dem Mac) gedrückt, um mehrere Bilder auf einmal zu markieren.
2. Eine Liste der ausgewählten Bilder erscheint im Arbeitsbereich. Jede Zeile zeigt ein kleines Vorschaubild, den Originalnamen, die aktuelle Dateigröße und den Ausgangsstatus "Ready".
3. Legen Sie Ihre Einstellungen im Konfigurationsbereich fest. Diese Parameter gelten für alle Bilder in der Liste. Wählen Sie in der ersten Spalte ("Größe ändern") unter "Größe ändern nach" Ihre Option ("Prozent" oder "Abmessungen"), tragen Sie "Breite", "Höhe" oder "Skalierung" ein, wählen Sie den "Anpassungsmodus" und aktivieren Sie bei Bedarf "Niemals vergrößern". Bestimmen Sie in der zweiten Spalte ("Ausgabe") "Format", "Qualität", "Hintergrundfarbe", "Dateinamen-Präfix" oder das Feld "Target file size (optional)". Es gibt keine separaten Einstellungen pro Einzeldatei.
4. Klicken Sie auf die Schaltfläche "Bild verarbeiten". Die Dateien werden nacheinander verarbeitet. Der Status jeder Zeile wechselt während des Vorgangs von "Ready" zu "Processing..." und schließlich zu "Done" mit der Angabe der neuen Dateigröße.
5. Sobald der Status einer Datei auf Done wechselt, wird das Download-Symbol in der entsprechenden Zeile aktiv. Klicken Sie auf das Symbol, um diese Datei zu speichern, und wiederholen Sie den Schritt für jedes Bild. Es gibt kein ZIP-Archiv und keine Option zum Herunterladen aller Dateien auf einmal.

## Unterschiedliche Bildformate handhaben: Hochformat und Querformat

Wenn Ihre Auswahl sowohl Querformat-Aufnahmen (breiter als hoch) als auch Hochformat-Bilder (höher als breit) enthält, führt die Vorgabe fester Werte für Breite und Höhe je nach Anpassungsmodus zu unterschiedlichen Ergebnissen.

Unter "Anpassungsmodus" stehen drei Optionen zur Verfügung:

* **Einpassen (skalieren, nicht beschneiden)** passt das Bild so an, dass es vollständig in den Zielbereich passt, ohne das ursprüngliche Seitenverhältnis zu verändern. Bleibt freier Raum im Zielfeld übrig, wird dieser mit der gewählten "Hintergrundfarbe" gefüllt.
* **Füllen (zuschneiden zum Ausfüllen)** skaliert die Aufnahme, bis das Zielfeld vollständig ausgefüllt ist. Bildteile, die über die Abmessungen hinausragen, werden von der Mitte ausgehend abgeschnitten.
* **Strecken (Seitenverhältnis ignorieren)** zwingt das Bild exakt in die angegebenen Werte für Breite und Höhe, unabhängig vom ursprünglichen Verhältnis, was zu Verzerrungen von Motiven führen kann.

Wenn jedes Foto seine natürlichen Proportionen ohne Zuschnitt und ohne Farbränder behalten soll, bieten sich zwei einfache Vorgehensweisen an:

* **Nur eine Abmessung eingeben**: Tragen Sie im Modus "Abmessungen" einen Wert bei "Breite" ein und lassen Sie "Höhe" komplett leer (oder tragen Sie einen Wert bei "Höhe" ein und lassen "Breite" leer). Das Werkzeug berechnet das fehlende Maß für jedes Bild individuell anhand des jeweiligen Originalverhältnisses.
* **Prozentmodus nutzen**: Stellen Sie "Größe ändern nach" auf "Prozent" und passen Sie den Schieberegler für "Skalierung" an. Eine Skalierung von 50% setzt Breite und Höhe jedes Fotos auf die Hälfte seiner ursprünglichen Größe und erhält die Proportionen von Hoch- und Querformaten gleichermaßen.

## Eine Zieldateigröße für mehrere Dateien festlegen

Wenn für Ihre Unterlagen eine feste Dateigrößengrenze gilt, beispielsweise bei Bewerbungs- oder Behördenportalen, können Sie im Feld "Target file size (optional)" einen Wert eingeben und "KB" oder "MB" auswählen.

Bei einer Vorgabe behandelt das Werkzeug jede Datei getrennt. Es passt Kompression und Auflösung schrittweise an, um jede Datei so nah wie möglich an die Vorgabe heranzuführen. Kann ein Bild den genauen Wert nicht erreichen, liefert die Anwendung das bestmögliche Annäherungsergebnis.

Wählen Sie bei Behördenformularen und Prüfungsportalen unter "Format" vorzugsweise JPG. Viele offizielle Systeme akzeptieren keine WebP-Dateien, auch wenn WebP für normale Websites gut geeignet ist. Weitere Hinweise zum Erreichen bestimmter Dateigrößen finden Sie in unseren Anleitungen [Bild auf 100 KB verkleinern](https://www.freeeimageresizer.com/de/blog/bild-auf-100-kb-verkleinern) und [Bildgröße auf 50 KB reduzieren](https://www.freeeimageresizer.com/de/blog/bildgroesse-auf-50-kb-reduzieren).

Falls Sie PNG als Ausgabeformat wählen, beachten Sie, dass Webbrowser keine verlustbehaftete PNG-Kompression unterstützen. Das Tool kann das Dateigewicht von PNGs daher nur durch die Verringerung der Pixelabmessungen senken.

## Dateinamen-Präfix und Benennung der Ausgabedateien

Beim Herunterladen werden die angepassten Bilder als neue Dateien auf Ihrem Gerät gespeichert. Ihre Originaldateien bleiben unverändert erhalten.

In der zweiten Spalte ("Ausgabe") können Sie das Feld "Dateinamen-Präfix" verwenden (Beispielplatzhalter "z.B. verkleinert"). Tragen Sie beispielsweise `web` ein, lautet der Dateiname `web-originaldateiname.ext`. Bleibt das Feld leer, behalten die Dateien ihren Originalnamen mit der Dateiendung des gewählten Formats (aus `foto.jpg` wird bei WebP-Ausgabe etwa `foto.webp`).

## Wissenswertes für die Mehrfachbearbeitung

Beachten Sie bei der Arbeit mit mehreren Dateien folgende Punkte:

* **Schrittweise verarbeiten**: Die Bilder werden nacheinander verarbeitet, um Lastspitzen beim Arbeitsspeicher zu vermeiden. Ein Stapel mit zwanzig Bildern dauert länger als zwei Bilder. Wenn Ihr Gerät langsam reagiert, probieren Sie einen kleineren Stapel aus.
* **Dateien mit Fehlern**: Sollte eine Datei beschädigt sein oder nicht gelesen werden können, erscheint in der Zeile der Hinweis "Error", während die übrigen Bilder ohne Abbruch weiterverarbeitet werden.
* **Liste leeren**: Die Schaltfläche "Alles löschen" leert die Liste und bringt Sie zurück zum Uploadbereich. Es gibt keine Option zum Entfernen einzelner Bilder aus der Liste; haben Sie ein Bild versehentlich hinzugefügt, können Sie über "Alles löschen" neu beginnen oder dieses Bild am Ende einfach nicht herunterladen.
* **Text zur Dateigröße**: Im Uploadbereich steht der Hinweis "Maximale Dateigröße: 50 MB."
