Möchten Sie Ihr zugeschnittenes Bild komprimieren? Probieren Sie unseren Bildkomprimierer.

Laden Sie ein Bild hoch, um mit dem Zuschneiden zu beginnen

Was kann dieses Zuschneide-Werkzeug?

Das Zuschneide-Werkzeug von ImageResizer schneidet Fotos und Grafiken direkt in Ihrem Webbrowser zu, ohne dass Dateien auf externe Server geladen werden. Passen Sie Bilder in den Formaten PNG, JPG, WebP, GIF, BMP oder AVIF auf exakte Pixelmaße oder feste Seitenverhältnisse an und laden Sie Ihr zugeschnittenes Bild als PNG-Datei herunter. Die Verarbeitung erfolgt vollständig lokal auf Ihrem Endgerät.

So funktioniert es

  1. Wählen Sie ein Bild von Ihrem Gerät aus oder ziehen Sie es in das Feld.
  2. Passen Sie den Rahmen mit den Anfassern an, tippen Sie Pixelmaße ein oder wählen Sie ein Seitenverhältnis.
  3. Klicken Sie auf Zuschnitt herunterladen, um das fertige PNG-Bild auf Ihrem Gerät zu speichern.

Das Zuschneiden basiert auf modernen Webstandards im Browser. Ihr Endgerät rendert das importierte Bild auf eine interne 2D-Canvas-Fläche. Wenn Sie die Anfasser verschieben, werden die Bildkoordinaten in Echtzeit neu berechnet. Beim Download wird der ausgewählte Bereich verlustfrei als PNG-Datei exportiert. Falls Sie eine optionale Zielgröße angeben, skaliert das Werkzeug die Abmessungen herunter.

Einschränkungen

Es gibt keine feste Begrenzung für Dateigrößen in diesem Werkzeug. Unsere Tests haben hochauflösende Bilder bis zu 55 MB fehlerfrei verarbeitet. Da sehr große Bilder Arbeitsspeicher Ihres Browsers belegen, hängt die Leistung von Ihrem Endgerät ab. Die Ausgabe erfolgt als PNG. Da PNG verlustfrei ist, ist ein zugeschnittenes JPG-, WebP- oder GIF-Foto meist größer als das Original; in unserem Test war ein 1:1-Zuschnitt eines 4000×3000-JPGs etwa 3,2-mal so groß wie die Quelle. Wenn Sie eine Zieldateigröße angeben, verkleinert das Tool die Ausgabemaße, um nahe heranzukommen; das Ergebnis ist also ungefähr, und ein kleines Ziel wie 100 KB kann trotzdem überschritten werden (166 KB in unserem Test); für genaue KB-Ziele nutzen Sie den Bildverkleinerer auf der Startseite oder das Komprimieren-Tool.

Häufig gestellte Fragen

Ist das Werkzeug kostenlos und werden meine Dateien hochgeladen?

Ja, das Zuschneide-Werkzeug ist vollkommen kostenlos und erfordert weder Registrierung noch Abonnements. Alle Vorgänge laufen lokal in Ihrem Browser ab, Ihre Dateien werden zu keinem Zeitpunkt auf fremde Server übertragen.

Welche Bildformate werden unterstützt?

Sie können Bilder in den Formaten PNG, JPG, WebP, GIF, BMP und AVIF öffnen und zuschneiden. Alle zugeschnittenen Bilder werden direkt als PNG-Dateien heruntergeladen.

Welche Steuerelemente und Seitenverhältnisse gibt es?

Sie können Breite und Höhe direkt als Pixelwerte eingeben oder die Anfasser am Auswahlrahmen ziehen. Verfügbare Verhältnisse sind Frei, 1:1, 4:3, 3:2, 16:9, 9:16, 2:3 und 3:4. Zudem können Sie eine optionale Zielgröße in KB oder MB vorgeben.

Gibt es eine Begrenzung der Dateigröße?

In diesem Werkzeug existiert kein festes Größenlimit für Bilddateien. In unseren Tests konnten Fotos bis 55 MB problemlos bearbeitet werden. Das Leistungsvermögen richtet sich nach dem Arbeitsspeicher Ihres Systems.

Verringert das Zuschneiden die Bildqualität?

Das Zuschneiden behält die exakte Schärfe der ausgewählten Pixel bei. Der PNG-Export erfolgt ohne Qualitätsverlust, weshalb die fertige Bilddatei im Vergleich zu einer komprimierten JPG-Datei mehr Speicherplatz einnehmen kann.
